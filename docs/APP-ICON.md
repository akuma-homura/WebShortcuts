# 应用自适应图标

应用图标根据用户提供的玻璃四宫格和向上箭头图制作。图中圆形底盘、白色外边和外部投影不写入图标前景，最终轮廓交给桌面启动器裁切。

- 背景使用覆盖整个 108 × 108dp 图层的矢量渐变，保持黄橙、粉紫、蓝色的流动配色。
- 透明前景保留玻璃面板、四个白色格子和蓝色箭头波面；源 PNG 为 1254 × 1254，存放在 `drawable-nodpi`，不会按默认资源密度先缩小。
- 前景通过 `InsetDrawable` 的 16% 比例留白定位。有效主体位于居中的直径 66dp 安全圆内；默认可见区域为 72 × 72dp，另外的图层空间供桌面裁切与动效使用。
- 普通与圆形入口共用相同自适应前景、背景和单色资源。前景不预裁成圆形，避免叠加白边或再次缩小。
- Android 13 及以上主题图标使用独立矢量轮廓，保留窗口、四宫格和箭头细节，由启动器选择着色。

`LauncherIconPreviews.kt` 通过实际 Android drawable，按 108/72 图层比例模拟圆形、圆角方形、超椭圆和水滴形，展示彩色、主题图标及小尺寸效果。`LauncherIconTest` 在设备上验证前景有效像素位于共享安全圆、背景完整不透明，并输出浅色和深色形状预览截图。
