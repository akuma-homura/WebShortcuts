# v1.2 验收清单

自动化测试覆盖可重复的逻辑和系统集成；启动器重绘及真实网站登录态需要真机验证。

## 自动验证

| 范围 | 验证内容 |
| --- | --- |
| URL | HTTPS 补全、IDN、IPv4/IPv6、内网、端口、拒绝非法协议与凭据 |
| 元数据 | 编码往返、旧字段迁移、稳定 ID、版本字段、重复/损坏数据拒绝 |
| 持久化 | 原子恢复、并发写入、删除、损坏文件不被覆盖 |
| 路由 | 显式目标 Activity，Intent 仅携带 ID，不含网址 |
| 图标 | 真实像素排序、根目录 Apple 兜底、相对链接、资源上限、SVG/ICO 安全边界、原图/离中心裁切与几何边界 |
| 界面 | 空状态添加、编辑模式切换、裁切确认/取消、Full Canvas 与安全区开关、来源/时间展示、未保存内容确认、屏幕截图 |
| 导入导出 | ZIP 原图/裁切/来源/外观往返，HTML 编码/目录平铺/去重，原子替换失败回滚、路径与容量边界、旧请求隔离、选择器取消与恢复 |
| 打包 | debug APK、release R8、Lint、Android 35 仪器测试 |

运行结果及失败详情由 GitHub Actions 保存。测试未通过时，不将对应项目标记为完成。

## 真机验收

1. **单包多站**：分别添加两个不同网站并固定到桌面，确认标签、图标独立。
2. **名称与图标热更新**：保持桌面快捷方式，编辑原收藏名称并改为自定义图标，保存后检查原有入口。必要时等启动器刷新，记录设备/启动器/系统版本。
3. **URL 路由**：固定网址 A 后，在应用中改成 B，不删除旧桌面图标，点击旧入口应打开 B。
4. **模式隔离**：导入自定义图，切 AUTO，再切 CUSTOM；不重新选图也应恢复原图。批量刷新不能更改 CUSTOM/GENERATED 收藏。
5. **非 PWA 与回退**：测试普通 favicon 站点、仅 Apple Touch Icon 站点、Manifest 站点、无图标站点；离线时可使用字母图标，保持 AUTO。更新旧构建后刷新全部自动图标，检查 32px favicon 不会抢先覆盖可用的 512px/SVG 原图，来源标签反映真实尺寸；透明/白底大边距 Logo、maskable 图、含四角文字图片在圆形与圆角桌面上均需检查主体大小和裁切，预览应接近桌面实际占比。
6. **解码与适配**：测试横向透明 PNG、32px favicon、JPEG EXIF 旋转图、WebP、多帧 ICO、普通 SVG；检查圆形和圆角预览没有拉伸。
7. **恶意/超大内容**：超大图片、伪装 MIME、SVG 外部资源、超时站点被拒绝，界面不挂起。
8. **真实登录**：在 Chrome 登录目标网站，从应用及桌面打开，确认进入同一个 Chrome 用户配置。网站自身会话过期不视为应用能自动修复的问题。
9. **删除**：删除收藏后旧桌面入口不可继续访问原网址。
10. **保存与恢复**：编辑过程中旋转、切到选图器、返回、进程重建；检查字段和已导入图片。磁盘写入失败不应清空已有收藏。
11. **布局**：浅/深色、Android 12+ 壁纸动态色、窄屏、横屏、200% 字体、键盘弹出、TalkBack。检查页面/收藏/分区/辅助文字层级为 22/16/14/12sp；150% 及以上字体时网格自动改为单列且偏好不丢失；预览芯片、取景选项和裁切滑块标签能换行，内容滚动后可达，交互区域不小于 48dp。
12. **权限**：安装包不得声明 READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE / READ_MEDIA_IMAGES。仅按用户选择的 URI 导入图片。
13. **自由裁切**：导入同时包含左右不同主体的图片，拖动与四角调整选择离中心区域，分别试自由比例、1:1、重置和滑块；取消不改预览，应用后保存。退出再编辑、旋转和进程恢复后应继续从私有原图调整；丢失预览草稿可以重建，丢失新原图草稿不能误用旧原图覆盖。
14. **预览边界**：切换桌面遮罩与 Full Canvas、圆形/圆角和安全区开关，比较实际可见范围；保存后的图标不应带网格、蒙层或虚线。
15. **刷新反馈**：下拉和菜单刷新均显示逐项 loading、完成数量和结果摘要；连续点击不重复请求，离线失败保留图标、来源及上次成功时间。检查无 HTML 声明但根目录有 Apple 图标的站点；长按来源 URL 可复制。区分本地更新成功与桌面同步待重试，时间不会伪称启动器已重绘。
16. **完整备份**：同时准备 AUTO/CUSTOM/GENERATED 收藏和非居中裁切，导出 ZIP 后在测试安装中恢复；确认原图可再次裁切、未启用模式的图片保留、图标没有重复缩小，来源时间不伪称本次获取。默认不改外观，勾选后即时恢复且重启保留。
17. **浏览器互通**：用 Chrome、Edge、Firefox 导出的 HTML 测试中文名称、嵌套目录、重复完整网址、带查询/fragment 的独立网址和非 HTTP 链接；导入无效项显示计数，HTML 导出可由浏览器重新读取。确认不自动抓图或迁移登录态。
18. **导入事务**：合并保留本机重复项及同网址不同 ID 定制；重复导入不增长。替换再次确认，空/无有效网址的 HTML 不能清空收藏。测试取消、URI 失效、空间不足、损坏 ZIP、后台旧抓图和旋转/进程重建，失败后原收藏与图片仍可读；新设备不自动添加桌面图标。

19. **标签筛选**：新建、重命名和删除标签，确认大小写同名和超长名称被拒绝；空标签保留。点击卡片标签不打开网页，多个标签按交集；普通搜索匹配标签名并与筛选共同生效，「无标签」只显示无关联收藏，清除搜索与清除标签独立。
20. **批量与草稿**：长按进入多选，全选范围限定当前结果；批量添加、移除不影响其他标签，完成后退出多选。取消编辑不残留新标签；新收藏继承筛选。旋转/进程重建恢复查询、筛选、所选收藏和待保存标签；冷启动显示全部。200% 字体可滚动选择并保存，标签行与按钮保持触控尺寸。
21. **标签备份与并发**：ZIP 往返保留目录、空标签和关联；冲突按 ID 再名称映射，重复收藏仅补充标签，重复导入不改动元数据。旧 ZIP/HTML 合并保留标签，替换清空并二次提示。模拟落盘失败时目录与关联同时回滚；抓图、旧编辑草稿及排队操作不会覆盖新标签。纯标签修改不增加图像版本、不更新桌面入口。

22. **自动排序**：首次使用收藏默认最近添加、标签默认名称升序；切换时间、名称、数量及升降序，确认中英文排序、同值稳定、空标签可见，列表与网格一致。重启记住方式，自动模式没有整理入口，切回手动保留原顺序。
23. **手动整理**：拖动手柄跨屏并触发边缘滚动，或从菜单及 TalkBack 上移/下移；长按仍多选。搜索或交集筛选后只交换结果所在槽位，隐藏项目不动；标签搜索同样支持。完成保存，返回取消；200% 字体能到达完成/取消，保存期间不能重复提交。
24. **排序恢复与并发**：旋转或进程重建恢复有效整理草稿。模拟图标刷新，保存后最新字段不丢失且排序不改变图像版本/更新时间；删除或导入使旧草稿失效。写入失败保持原顺序并可重试。ZIP 往返保留收藏/标签手动顺序，HTML 保留收藏顺序；恢复外观也不改本机排序偏好。

25. **标签输入**：编辑和管理各只有一个输入框，实时筛选；软键盘搜索键、实体回车与数字键盘回车只搜索并收起键盘，＋可连续添加。编辑面板未点＋直接保存也会提交，保存前提示添加/选择效果。中文组词期间不搜索、不添加且不能保存。大小写同名复用/提示，过长名称和落盘失败保留输入与选择；编辑收藏取消不残留目录，管理成功后清空且可继续输入。纯筛选与批量移除没有＋，查询不创建标签。
26. **标签密度与恢复**：320/360dp 检查多列选择、管理同行计数、收藏宽度自适应标签及 `+N`。已选和待新建标签的 × 点击区至少 48dp，只取消本次选择，不删除目录或其他收藏关联；点击只生效一次，清空输入后保存不重新添加。200% 字体退为单列且＋/保存/×可操作，长名称仍能选择。旋转与进程重建恢复未提交文字；排序、重命名和全局删除保留查询，原有筛选、多选和手动顺序保持有效。

27. **应用图标适配**：在圆形、圆角方形、超椭圆和水滴形下检查玻璃面板、四宫格与向上箭头完整可见，背景覆盖整个遮罩且无截图白边。检查小尺寸清晰度与 Android 13 以上主题图标，正常与圆形入口一致；不同图标尺寸维持相同比例留白。

## 发布前仍需完成

- 用真实 Android 设备覆盖 Pixel Launcher 和至少一个常用 OEM 启动器。
- 使用长期维护的正式签名生成发布 APK/AAB，并验证从上一签名版本升级的数据保留。
- 若准备公开分发，补充项目许可证、应用商店素材和真实隐私政策网址；当前未替项目擅自选择开源许可证。

## v1.5 新增验收

1. 同一站点分别指定 Chrome、Chrome Beta、Firefox；应用与桌面打开均进入所选浏览器，在各浏览器预先登录不同账号后人工确认会话。修改浏览器后原桌面 UUID 仍路由到新选择；卸载选定浏览器时显示提示，不自动切换账号。
2. 导入 UTF-8/UTF-16 HTML、Chrome 保存的 MHTML、`.mht`，移动/删除原文档后再打开；飞行模式下文字、内联样式/图片和 MHTML 嵌入资源可见；网页脚本不执行，在线资源不请求。
3. 修改本地名称、图标、标签、更换文件、保存并更新桌面；进程重建后草稿仍可保存。损坏、空、超过 32 MiB、权限丢失的文档给出可恢复反馈。
4. 完整 ZIP 往返保留浏览器选择与 HTML/MHTML 字节；旧备份迁移成功。通用书签 HTML 仅导出在线项目且报告跳过数。
5. 浅色、深色、动态色和五套色板：主页、网格、编辑器、设置、浏览器选择、标签、排序、备份与离线查看器保持语义层级。200% 字号下文字、按钮仍可滚动访问；关闭系统动画后操作和加载正常。
6. 回归已有收藏、标签、排序、图标发现/裁切、桌面固定、导入恢复、并发与回滚测试。

真实第三方账号、特定 OEM 启动器和供应商 WebView 版本仍需在目标设备上验收；自动 Intent 绑定测试不等价于登录第三方网站。
