# WebShortcuts

把常用网站放进一个轻巧的 Android 应用，为每个网站创建独立的桌面快捷方式。

WebShortcuts v1.5 使用 Kotlin、Jetpack Compose 和 Material 3 Expressive。支持 Android 8.0（API 26）及以上，面向 Android 16（API 36）。收藏、图标与导入的本地网页默认保存在设备私有目录，可手动导出到所选文件位置；不包含账号系统、自动云同步或统计 SDK。

## 功能

- **网站收藏**：新增、编辑、删除、名称/网址/标签搜索，也可以从浏览器分享网址到 WebShortcuts。
- **标签分组**：一个收藏可关联多个标签；点击标签或搜索名称筛选，多选标签取交集，支持「无标签」。编辑器和收藏菜单可改标签，长按多选可批量添加或移除；标签管理可新建、重命名、删除，删除标签不会删除收藏。选择面板使用紧凑多列标签，管理列表同行显示数量；新标签回车即可添加，也可在保存标签时一起提交。搜索与新建输入独立。
- **自动与手动排序**：收藏按添加时间、更新时间、名称排序，默认最近添加在前；标签按名称或全库收藏数量排序，支持升降序。切换手动后可拖拽整理，也可从菜单上移、下移；筛选内只调整可见位置，隐藏项目保持原位。排序方式留在本机，ZIP/HTML 按保存顺序导出，ZIP 同时保留标签顺序。
- **完整备份与恢复**：ZIP 包含收藏、浏览器选择、导入的 HTML/MHTML 文件、标签目录及关联、自动/自定义图标、可编辑原图、裁切参数、来源时间及外观设置。先预览再合并或全量替换；重复 ID 保留本机内容并补充新标签，不同 ID 的同网址定制可同时保留。外观恢复默认关闭。
- **浏览器书签互通**：导入或导出 Chrome、Edge、Firefox 通用的 Netscape HTML 书签。文件夹中的书签平铺导入，按完整网址去重，仅接受 HTTP(S)；HTML 不携带标签、图标定制或浏览器登录态。
- **三种图标模式**：自动发现网站图标、系统 Photo Picker 导入图片、根据名称生成字母/汉字图标。模式显式切换，自定义图片不会被自动刷新覆盖。
- **自由裁切**：拖动选区、调整四角、切换自由比例与 1:1，也可用尺寸/位置滑块精确调整；支持重置、取消和应用。保留私有原图和裁切参数，保存后仍可重新编辑，不会在已缩小的图标上反复裁切。
- **预览与安全区**：圆形/圆角桌面遮罩、Full Canvas 完整画布、安全区蒙层与桌面可见边界；辅助线仅用于预览，不写入图片。
- **自适应应用图标**：玻璃四宫格与向上箭头使用独立透明前景，彩色渐变背景铺满画布；主体放入 Android 共享安全区，适配圆形、圆角方形、超椭圆和水滴形，并提供独立的主题单色图标。
- **自动图标**：解析 Web App Manifest、Apple Touch Icon、HTML 图标，并尝试根目录 `/apple-touch-icon.png`、`/apple-touch-icon-precomposed.png` 和 `/favicon.ico`；优先寻找 SVG 或 512 像素原图，按真实解码尺寸选择，不把放大的小 favicon 当作高清；支持 PNG、JPEG、WebP、安全 SVG 与 ICO 的 PNG/DIB 帧。
- **刷新反馈**：首页下拉或菜单批量刷新，显示逐项状态、完成数量及可关闭的结果摘要；编辑器展示可复制的来源 URL 和最近成功获取时间。抓取成功与桌面同步待重试分别反馈，失败保留缓存和上次成功时间。
- **可靠回退**：离线、解码失败或没有网站图标时显示生成图标；刷新失败保留可用缓存，模式继续保持 AUTO。
- **顺畅保存**：自动抓图尚未完成时也能先保存收藏；缺失的自动图标在后台继续获取，返回时再次检查当前模式和版本，避免覆盖后续编辑。
- **桌面同步**：修改名称、网址或图标后更新相同 UUID 的已固定快捷方式。桌面入口只携带书签 ID，点击时读取最新 URL。
- **每个快捷方式独立选择浏览器**：发现已安装且能打开网页的 Chrome、Chrome Beta、Firefox 等浏览器，优先使用对应 Custom Tabs 并复用其正常登录状态；不支持 CCT 的浏览器在同一浏览器内打开。明确指定的浏览器不可用时提示更换，不切换到其他账号。自动模式仍提供兼容回退。
- **HTML / MHTML 离线网页**：从文件选择器导入 `.html`、`.htm`、`.mhtml`、`.mht`，或由文件管理器打开/分享。先复制到私有目录，再编辑名称、图标、标签并添加到桌面；原文件移动后仍可阅读。首页可筛选在线/本地网页。
- **个性化外观**：Android 12+ 默认使用壁纸动态配色，也可选择翡翠青、深海蓝、落日琥珀、鸢尾紫、樱花粉五套完整明暗色板；支持跟随系统、浅色和深色模式，设置保存在本机并即时生效。
- **Material 3 Expressive**：统一 ColorScheme、字阶、表面层级与明暗主题；首页与编辑器使用集中封装的 TonalCard 和胶囊按钮，外观、排序和浏览器选择使用官方连体列表。选中、按压、加载、弹窗才启用表达性形状与 MotionScheme 动效，遵循系统动画缩放；150% 以上字体下网格自动单列，交互目标至少 48dp。
- **隐私与资源限制**：只声明网络权限，无全盘/相册读取权限；文本、图像大小与分辨率均受限。

## 多账号与离线网页

同一个网站可以保存多份，例如「GitHub · 工作」选择 Chrome，「GitHub · 个人」选择 Chrome Beta。先在各浏览器正常登录，随后在编辑器的「打开方式」中指定浏览器。应用和桌面入口都会读取最新的选择。相同浏览器的多个快捷方式共享该浏览器的正常会话；本应用不创建浏览器内部的独立账号容器，也不读写、备份或迁移 Cookie。

首页文件夹按钮或空列表的「导入本地网页」打开系统文件选择器。单个文件最多 32 MiB；HTML 需要自包含的内联/数据资源，邻接的资源文件夹不会一起导入；MHTML/MHT 使用 WebView 原生归档能力读取嵌入的图片和样式。离线查看器不运行导入文件的 JavaScript，不加载网络资源。点击在线链接时先确认，再交给浏览器。该功能用于离线阅读，依赖脚本的交互式网页不是本版本的支持范围。

完整 ZIP 备份保留浏览器选择和离线内容，恢复时重新分配私有文件名。通用浏览器书签 HTML 仅导出在线网址，界面明确显示跳过的本地项目；这与「导入本地网页」是不同操作。

设计规范、实施阶段与验收覆盖见 [Expressive 设计系统](docs/EXPRESSIVE-DESIGN.md) 和 [v1.5 实施与验证](docs/IMPLEMENTATION-v1.5.md)。

## 获取 APK

打开仓库的 **Actions → Android CI → 成功的运行记录 → Artifacts**：

- `WebShortcuts-debug`：解压后的 `app-debug.apk` 可直接侧载安装，适合功能体验。
- `WebShortcuts-release`：启用 R8 并由固定正式密钥签名的发布包，供日常安装和后续覆盖升级；仅在仓库配置签名密钥时生成。
- `WebShortcuts-release-unsigned`：启用 R8 的未签名发布包，供自行签名。
- `verification-reports`、`device-test-reports`：单元测试、Lint 和设备测试结果。
- `device-screenshots`：Android 模拟器实际渲染的浅色、深色和编辑页截图，演示数据只存在于测试中。

每个构建的 debug 签名由 CI 环境生成，跨运行安装时可能需要先卸载旧 debug 包。卸载会删除本地收藏；正式长期使用请维护固定的发布签名。发布签名和密钥不会写入仓库。

## 将 APK 发布到版本标签

Android CI 的手动发布使用两个可选字段：`publish_tag` 和 `build_run_id`。留空时正常构建和测试；填写版本标签及已成功的 CI 运行 ID 时，只发布这次运行的产物，不重复构建。

先对目标 tag/分支运行 Android CI，等待构建、Lint 和 Android 35 设备测试成功，再使用对应 tag 与运行 ID 执行发布。任务会核对同仓库、精确提交 SHA、APK 版本、内嵌源码版本及测试报告；生成带来源运行 ID 的 APK、SHA-256 和构建信息，上传后重新下载校验，最后发布对应 Release。不会移动标签或覆盖同名附件。

排查设备测试失败时，可单独填写 `inspect_run_id` 读取该次运行的完整 JUnit 失败信息，不构建或发布应用。

正式发布使用仓库固定签名密钥；稳定版本标签且正式签名校验通过后才会标为正式 Release 和 Latest。Release 同时提供正式签名 R8 APK、临时签名 Debug APK、未签名 R8 APK、SHA-256 校验值和含证书指纹的构建来源记录。后续保持同一正式密钥即可覆盖升级。更换旧版或 CI 测试签名前，请先导出 ZIP 备份，卸载旧包后安装正式版并恢复。

仓库维护者需在 Actions Secrets 配置 `RELEASE_KEYSTORE_BASE64`（完整 JKS/PKCS12 文件的 Base64）、`RELEASE_KEYSTORE_PASSWORD`、`RELEASE_KEY_ALIAS` 和 `RELEASE_KEY_PASSWORD`。签名脚本兼容 CRLF 换行、Base64 换行和 URL-safe 编码，密码通过环境变量传递；临时解码文件在签名后删除。密钥与密码应另行安全备份，不得提交到仓库。没有密钥时仍可运行构建与设备测试，但只提供测试构建，不发布为正式版本。

## 本地构建

安装 JDK 17、Android SDK Platform 37.0 和 Build Tools 36.0.0，然后用 Android Studio 打开仓库，或配置 `ANDROID_HOME` / 未跟踪的 `local.properties`：

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug
./gradlew :app:assembleRelease
# 启动 Android 模拟器或连接设备之后：
./gradlew :app:connectedDebugAndroidTest
```

Windows 使用 `gradlew.bat`。Gradle Wrapper 已包含在仓库中，无需手工安装 Gradle。

工具链固定为 AGP 9.1.1、Gradle 9.3.1、Kotlin 2.2.21、Compose BOM 2026.09.00；Material 3 显式使用 `1.5.0-rc01`（发布候选版本），以启用官方 Expressive API。构建依赖从 Google Maven 和 Maven Central 获取。

`app/src/debug/.../ui/SortingPreviews.kt` 提供排序设置、手动整理和大字体预览；`TagPreviews.kt` 提供标签列表、网格、批量整理、标签面板和大字体预览；`CompactUiPreviews.kt` 提供列表、网格、深色、图标编辑器、外观设置与 200% 字体预览；`LauncherIconPreviews.kt` 提供应用图标在四种桌面形状、浅深色和主题模式下的预览。Android Studio 可直接渲染；安装 Android CLI 后也可运行 `android preview render :app --fqn=io.github.homura251.webshortcuts.ui.LauncherIconPreviewsKt.LauncherIconLightPreview --component-tree`。应用图标资源与安全区约束见 [APP-ICON.md](docs/APP-ICON.md)。这些预览仅使用本地资源和演示数据。

## 使用方式

1. 新建网站，输入网址和名称。省略协议时默认补全 HTTPS；可显式输入 HTTP 来访问局域网站点。
2. 选择自动、自定义或字母生成图标，检查预览并保存。
3. 在收藏右侧菜单选择「添加到桌面」，按系统提示确认。
4. 后续编辑同一收藏并保存，应用会请求原地更新已有桌面图标；启动器何时重绘由设备决定。
5. 点击首页右上角的调色板打开「个性化外观」，调整配色、深浅色和布局；选择精选色板会关闭壁纸动态配色。首页统计区也可直接切换列表与网格。
6. 首页更多菜单打开「导入 / 导出」。导出完整备份用于迁移图标与收藏，导出 HTML 用于浏览器；两种格式均导出全部收藏，不受搜索或标签筛选影响。系统文件选择器决定保存位置，无需存储权限。
7. 选择 ZIP 或 HTML 导入后，先检查新增、重复、无效条目和图像异常摘要。默认合并并保留本机重复项；全量替换需要再次确认。HTML 没有有效网站时禁止替换。恢复 ZIP 可勾选恢复外观；导入不会自动添加桌面入口或联网抓取图标，之后可手动刷新。

8. 点击搜索框旁的标签按钮，选择一个或多个标签；首页搜索文字与标签筛选共同生效。长按收藏进入多选，「全选」仅选择当前结果，再点「添加标签」或「移除标签」。清除搜索与清除标签互不影响；新建收藏继承当前选中的标签。
9. 更多菜单打开「标签管理」。标签名称去首尾空白，限 1–40 字符且忽略大小写判重；可保留空标签。ZIP 会保留标签，HTML 继续平铺；旧 ZIP 或 HTML 全量替换时会清空标签，二次确认会明确提示。

10. 点击首页统计区的排序按钮，选择添加时间、更新时间、名称或手动排序。自动排序只改变展示；切回手动仍保留原顺序。选择手动后点击「整理顺序」，完成保存或返回放弃，长按多选仍保留原用途。标签管理面板可设置标签排序，标签选择和卡片使用同一顺序；「全部收藏」「无标签」固定在前。

11. 标签编辑和管理使用同一个「搜索或添加标签」输入框：输入实时筛选，回车确认搜索，点右侧＋添加。编辑面板保存时也会添加尚未确认的文字，下方会提示保存效果。已选标签和待新建标签的 × 只取消本次选择，点选或移除后清空输入；收藏编辑仍随收藏保存后生效，取消不会创建标签。管理面板点＋立即创建，成功清空并保持焦点，失败保留输入；重命名或删除保留搜索。纯筛选与批量移除面板只提供搜索。

ZIP 使用格式版本 2，继续读取版本 1；包含 `manifest.json`、schemaVersion 5 的 `bookmarks.json`、`appearance.json`、图像文件和 `pages/` 中的本地网页。最多 2000 条收藏、2000 个标签，HTML/收藏 JSON 上限 4 MiB，ZIP 文件与解压总量各上限 256 MiB。备份不加密，包含网址与图片，请妥善保存。缓存中已缺失的图像会明确提示并从备份引用中移除；原图存在时继续保留原图和裁切参数。文件损坏、版本不支持或导入失败时保留现有收藏。

自动获取图片不会获得 Chrome 的 Cookie；仅登录后可见的图标可能无法下载，此时可使用自定义图片。浏览器登录态由浏览器、用户配置和网站自身策略管理，应用不能保证所有网站永久保持登录。

从早期构建更新后，请在首页菜单选择「刷新所有自动图标」，以重新下载原图并应用新的尺寸处理；未保留原图的旧自定义图片需要重新导入一次，之后即可重复编辑。已缓存的小图无法恢复丢失的细节。透明或纯色外边距会在适配时去除，Manifest 的 maskable 图标会使用其现有安全区；圆形/圆角预览显示桌面的实际可见区域，最终外形和刷新时机仍由启动器决定。

## 工程说明

```text
app/src/main/java/io/github/homura251/webshortcuts/
  data/       本地元数据、格式迁移、URL 校验
  icons/      网站图标发现、受限解码、私有图片存储、最终图标解析
  shortcuts/  固定/更新快捷方式、UUID 路由、Custom Tabs
  transfer/   ZIP/HTML 文件格式、导入预检、事务与文件选择器状态
  ui/         Material 3 界面与主题
  MainViewModel.kt  编辑事务、异步任务与批量刷新协调
```
